# 🛠️ AlmoxControl

Sistema de controle de ferramentas desenvolvido para facilitar a organização, movimentação e acompanhamento de itens dentro de um almoxarifado.

O projeto nasceu a partir de uma necessidade real observada em ambiente de trabalho: melhorar o controle de entrada e saída de ferramentas, evitando perdas, falta de rastreabilidade e dificuldades na organização do estoque.

---

## 📌 Sobre o Projeto

O AlmoxControl é uma aplicação web para gerenciamento de ferramentas, permitindo visualizar informações como:

- Quantidade total de ferramentas
- Ferramentas disponíveis
- Ferramentas em uso
- Ferramentas em manutenção
- Histórico de movimentações

O objetivo é criar uma solução simples, visual e eficiente para pequenos almoxarifados.

---

## 🚀 Funcionalidades

### Dashboard
- Visualização rápida dos principais indicadores
- Cards informativos
- Resumo geral do estoque

### Ferramentas
- Cadastro de ferramentas
- Visualização dos itens cadastrados
- Controle de disponibilidade

### Movimentações
- Registro de retirada e devolução
- Histórico de movimentações
- Controle de utilização das ferramentas
